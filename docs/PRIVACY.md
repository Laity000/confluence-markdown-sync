# Privacy Policy / 隐私说明

Last updated: 2026-10-13

This browser extension converts Markdown to Confluence Wiki Markup or Storage XHTML and, only when a user requests it, synchronizes the result to the user's selected Confluence Server/Data Center page.

- The extension does not request, read, or store Confluence account passwords or cookie values. It relies on the user's existing browser login session when making same-origin requests to the selected Confluence website.
- Markdown input, Confluence page content, and conversion results are processed within the user's browser. The extension sends page content **only to the Confluence server selected by the user** in order to read, preview, or publish the page, and does not upload those materials to a developer-operated analytics service.
- The extension stores the URL of the most recently used target page locally using Chrome extension storage; it does not persist the Markdown editor contents. The user may clear extension storage or uninstall the extension.
- Backup files are created only when the user explicitly requests them; files are saved to the user's browser download directory.
- The extension does not include analytics, advertisements, trackers, or third-party remote code.
- Existing Confluence account permissions, content retention, logging, and privacy policies are governed by the user's Confluence administrator and organization. If the selected Confluence server uses HTTP rather than HTTPS, login sessions and content may be exposed during network transmission. HTTPS is strongly recommended.

Contact: Please open an issue in the project's GitHub repository if you have a question about the extension's behavior. Do not include enterprise credentials or private documents in the issue.
